# مدى | Mada

**منصة العمل عن بعد القائم على المخرجات.** تقيس الإنتاجية بالمخرجات المعتمدة لا بالحضور، وتقارنها بخط أساس من الأسابيع الحضورية السابقة، وتدير الأهلية والاعتمادات والاعتراضات والإنذار المبكر وسجل التدقيق، وتولّد تقريراً تنفيذياً للقيادة.

> نموذج أولي يعمل بالكامل داخل المتصفح ببيانات وهمية، ولا يتصل بأي خادم.

## الأدوار
| الدور | ما يراه |
|---|---|
| صاحب القرار | اللوحة الاستراتيجية، والتقرير التنفيذي، ومعايير النجاح، وسجل التدقيق |
| المدير المباشر | لوحة القيادة، ومركز الإجراءات، والفريق والمحاسبية، والمخرجات والمهام، ومنصة كفاءة |
| الموارد البشرية | كل ما سبق، إضافة إلى القواعد والميثاق ووضع استمرارية الأعمال |
| الموظف | "مداي"، وحاسبة التقدير الذاتي، ومهامي، ومنصة كفاءة |

## التشغيل محلياً
السياسة الأمنية تسمح بالسكربت من الملفات المحلية فقط، فشغّل خادماً بسيطاً:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

لنسخة من ملف واحد تُفتح مباشرة أو تُرسل بالبريد:

```bash
node scripts/build-standalone.mjs
```

## النشر على GitHub Pages
1. ارفع المستودع إلى GitHub على الفرع `main`.
2. في **Settings ← Pages** اختر المصدر **GitHub Actions**.
3. يُنشر الموقع تلقائياً مع كل دفع إلى `main` عبر `.github/workflows/pages.yml`.

## البنية
```
index.html              الهيكل وسياسة أمان المحتوى
assets/css/mada.css     نظام التصميم: الرموز والمكونات والتجاوب والطباعة
assets/js/app.js        البيانات، والاحتساب، والمحرك التحليلي، والصفحات، والإجراءات
assets/favicon.svg      علامة "خط الأفق"
scripts/                بناء نسخة الملف الواحد
docs/AUDIT.md           التدقيق التقني وقرارات التحويل والقيود المعروفة
original/               الملف الأصلي قبل التحويل للمرجعية
```

## الهوية
- **خط الأفق**: مسطرة واحدة تضع خط الأساس الحضوري ومؤشر الأداء الحالي جنباً إلى جنب.
- **ذهب الأفق** (`#F2B33D`) لون واحد بمعنى واحد: موقعك الآن.
- **البترول العميق** (`#0C2830`) إطار مؤسسي ثابت في المظهرين.
- الخطوط: Alexandria للعناوين والأرقام، وIBM Plex Sans Arabic للنص.

## قبل الانتقال إلى الإنتاج
راجع القسم 3 في `docs/AUDIT.md`. باختصار: تُنقل الصلاحيات والحسابات وسجل التدقيق إلى خادم داخلي، ويحدد الدورَ تسجيلُ الدخول، وتُستضاف الخطوط محلياً، وتُضبط رؤوس الأمان في الخادم.
